# Download XML from PubMed Central

Download XML from PubMed Central

## Usage

``` r
pmc_xml(id)
```

## Source

<https://europepmc.org/RestfulWebService>

## Arguments

- id:

  a PMC id starting with 'PMC'

## Value

`xml_document`

## Examples

``` r
if (FALSE) { # \dontrun{
doc <- pmc_xml("PMC2231364")
} # }
```
